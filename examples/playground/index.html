Intégration

Chargement direct des assets, sans dépendance à Astral Core.

Copiez les fichiers src/ dans le répertoire public de votre application, ou utilisez le package Composer / NPM selon votre chaîne de déploiement.

<link rel="stylesheet" href="/assets/nova/core/index.css">
import { createInteractions } from '/assets/nova/javascript/index.js';
createInteractions();

Le bundle de distribution dist/nova.css est généré avec npm run build après installation des dépendances.
